What this site is

This is a research programme's public window. It is not a paper, not a preprint server, and not a blog. Its single organising rule is that a stranger opening any page should be able to tell what is defined, what is assumed, what is machine-checked, what is conjectured, and what is merely predicted — and should be able to begin checking without having to believe anything first.

What this site is not

How to cite

There is no DOI, so citations should point at the page and its retrieval date. A machine-readable citation file accompanies the source release, carrying the ORCID above.

A note on the absence of a DOI. Going straight to a website rather than to a preprint server was a deliberate choice, and it has a cost that is stated rather than hidden: there is no third-party timestamp and no citation record. Content here can be read and downloaded by a human, but it is not indexed by scholarly infrastructure. The site's own immutability page is explicit that its hashes prove integrity, not priority.

How to criticise this work

The most useful thing a competent reader can do is run the reproduction command and report what it says. The second most useful thing is to identify a statement in the ledger whose tag overstates its evidence. Both are welcome; neither requires believing anything on this site first.
