How it works · 如何验证

Each published file is hashed with SHA-256, then the hash is anchored to Bitcoin via OpenTimestamps. 每个已发布文件先以 SHA-256 取哈希，再将哈希通过 OpenTimestamps 锚定到比特币。Anyone can re-verify independently:

sha256sum FILE ots stamp FILE # 生成 FILE.ots ots upgrade FILE.ots # 取回 Bitcoin 确认 ots verify FILE.ots # 任何人可验证

This page's status for each entry is computed from the actual attestation inside its .ots file. 本页每一行的状态由对应 .ots 文件中的实际 attestation 计算；未确认只显示 pending。

OpenTimestamps only proves that a file existed at a point in time. OTS 只证明文件在该时间点存在，不构成发表、同行评审或优先权认定。It is not a claim of publication, peer review, or priority.
