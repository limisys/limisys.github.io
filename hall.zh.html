H1 · 对象层

边界＝闭包算子的不动点集

`Fix(c)` 就是边界；并且 三个看似不同的闭包算子是同一个构造（「最小上方已决元映射」`leastAbove`）的三个实例——偏序情形与范畴情形有对应字典。

机检证据：第70轮 `fix_c_eq_decided` · 第72轮 `isClosure_leastAbove` ＋三实例 · 第73轮 偏序↔范畴字典（EM 代数 ⇔ 不动点）· 第61轮 `FixV_eq_range`：不动点＝右伴随的像（显式描述）

推理脚手架 · 把结论压成这个形状的否定
  • 第67轮否掉「仅由 NonComm 决定 Fix」——两条不可能性；正因为边界不能由「不交换」定义，才必须由闭包不动点定义。
  • 第61轮把「越界的存在性否定」取窄：不是「桥不存在」，而是「桥在某个精确意义上存在」。
H2 · 值层

势的形式是被迫的——但只有一半

熵项是定理：`H(κ) = C_F/κ` 且对 κ 单调递减（是重标度律的权-(−1) 等变性）。κ★ 是 V 的唯一全局最小，两端极限有 ε–δ 形式。`value_layer_form_forced` 已机检。

机检证据：第62轮 `V_global_min` / `V_gt_near_zero` / `V_gt_atTop` · 专题「靶心3」`value_layer_form_forced` · P4 达成：值层代数核 Lean 编译通过

推理脚手架 · 把结论压成这个形状的否定
  • 第56轮 `sigmaStar_not_forced_one`：一般层推不出数值 1——所以 σ*=1 只能是规范条件，不是推论。
  • 第120轮 `no_gaugeInv_identification`：不存在规范不变的识别。
  • ⇒ 「只有一半被迫」本身是正面结论：公理产出形式，可证地不产出系数。
H3 · 三成分

「模糊」与「不确定」是两回事（前者一词retired／已退役）

三成分场已分离：`p_U ≤ b`，且 `b − p_U = 2·min(p_S, p_N)`；`b = p_U` 当且仅当 p_S 或 p_N 为零。b 是平衡度量，不是不确定性度量。

机检证据：第63轮 `pU_le_b` / `b_sub_pU_eq_two_min` / `b_eq_pU_iff` / `core_b_eq`（Lean exit 0）

推理脚手架 · 把结论压成这个形状的否定
  • 同一个第63轮给出 `no_function_of_b`：反例 `totallyUnknown`（全无知）与 `maximallyBalanced`（对半分）同给 b=1 ⇒ 不存在 f 使 p_U=f(b)。
  • ⇒ 正面结论正是被这个反例逼出来的：不是先有「模糊≠不确定」的想法，是反例不给别的选择。
H4 · 量纲

锚定的自由度恰为一，且两侧都已机检

值层缩放结构已机检：锚定只固定一个整体尺度，自由度恰为一；闭包侧的等变性也已补上——`anchoring_freedom_done_both_sides`。

机检证据：第77轮 `anchoring_fixes_one_degree` · 第78轮 `fix_rescale_image` / `anchoring_freedom_done_both_sides`

推理脚手架 · 把结论压成这个形状的否定
  • 第78轮同步更正了 8 处「闭包侧未机检」的旧范围声明——正面结论成立的同时，旧的免责声明也要撤销。
  • 专题「量纲钻研」自陈：V(κ) 没有内在量纲，论文靠规范参数把量纲压平成纯数，*「这是个真实漏洞」*——这一根柱子旁边挂着本线唯一自认的漏洞。
H5 · 读出

内禀读数存在·唯一·与 F 无关

在自身单位尺度上读自己的核，得到 `2/(1+e)`：尺度中心无关、与倒数路线同值、唯一。R(w)=1/w 的存在性、唯一性、不依赖 F 三件全部机检；N1/N2/N3 三张证书已打包。

机检证据：第107轮 `R_fixed_exists` / `R_fixed_unique` / `R_indep_of_F` · 第109轮 `n1_n2_n3_certificate` · 第111轮 `unitRead_scale_center_invariant` / `unitRead_agrees_reciprocal` / `unitRead_unique`

推理脚手架 · 把结论压成这个形状的否定
  • 🔴 第112轮 · 前提审计：被问「R 是系统自身的读出映射，证了么？」——回答是「没有」；四处措辞当场撤回。
  • ⇒ 正因为那条否定，这一根柱子的措辞才只能写成「定义了一个内禀读数」，而不是「由系统动力学导出读出」。
H6 · 水平

不存在规范不变的识别——一条决定性的否定结论

这是本线自己的主定理之一，而它是否定性的：规范不变的选取原则挑不出水平；能挑出的必破缺规范。T-θ‴ 四件结项，其中两件是否定性定理。

机检证据：第116轮 `gaugeInvPrinciple_notSelects` / `selfConsistency_selects` · 第120轮 `no_gaugeInv_identification`（主结果）· 第114轮 `unitRead_gaugeInv_level_blind`

推理脚手架 · 把结论压成这个形状的否定
  • 反例 `w=2`：破缺规范是必要而非充分。
  • ⚠ 请注意这一根的性质：它否定，但它是殿堂成员——因为它决定性地回答了「水平能不能被规范不变地定出」。否定 ≠ 失败；这是本陈列最想让人分清的一件事。
H7 · 可证伪

这条线第一次具备了能被实验打掉的形状

S4 落空条件已形式化：指数逼近的预言 ＋ 越界 / 回落 / 停滞 三条指名反驳。把判据从「关于算子的陈述」降到了「关于一个可测标量的陈述」：见证 ⇔ 存在 b 跨阈状态。

机检证据：第86轮 `witness_iff_b_crosses` / `protocol_core` · 第119轮 `level_geometric` ＋ `falsifier_overshoot` / `falsifier_nonmonotone` / `falsifier_stalls`

推理脚手架 · 把结论压成这个形状的否定
  • 第86轮自陈：*「协议本身是规范，不是定理」*；第119轮自陈：*「本件不做任何测量」*、预言*「只在声明的模型内成立」*。
  • ⇒ 正面结论（有形状了）与它的边界（还没测）并排摆放——这才是完整的一根柱子。
七根柱子，全部机检；旁边挂着的否定结果不改变柱子的成立——它们解释为什么柱子只能长这样。
